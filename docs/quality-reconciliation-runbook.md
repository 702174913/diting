# 不确定云提交与额度人工核销（只读排查门禁）

决策：用户选择**证据人工核销**，不采用未经验证的自动回调推断；无 TaskId 时保持预占，待真实账单/控制台证据与双人审批后才设计受审计的更正入口。尚未提供该类证据或批准具体单笔更正。

适用：`SUBMIT_UNCERTAIN` / `SUBMIT_UNRECONCILED`、`QUOTA_UNSETTLED`、明确拒绝后退额待重试，以及云/图片处理最终失败。**此文不是授权自动退款、重提云任务或直接改生产库。**

## 候选发现

- ADMIN 使用只读 `GET /api/admin/ops/reconciliation?limit=50&afterId=...` 分页查看候选；响应只有内部任务 ID、状态/错误码、流水状态、是否有远端 TaskId、墓碑标记与创建时间。已删除任务也保留在账务核查范围内。OPERATOR/INVESTOR 不可使用；接口不返回用户 ID、原文、对象 key、远端响应或签名地址。
- 该接口按错误码筛选，是**候选队列，不是全账务完整性审计**。部署后仍须由获授权 DBA 对限定目标库做只读一致性核对：`quota_ledger` 的 `RESERVED` 对应任务是否缺失、已墓碑、终态或长期未推进；`daily_quota.reserved/consumed` 与流水汇总是否一致。核对 SQL/索引/时间窗先在隔离副本演练，不在生产库自动修数或导出个人信息。
- 查询前先按 `docs/quality-migration-runbook.md` 核对实例、迁移版本和备份；V7–V11 已在真实业务库执行并审计，但生产服务按用户决定保持停机。迁移完成不等于账务更正或生产上线许可。

## 单笔证据与裁决

1. 为每笔建立受控工单，记录内部任务 ID、创建/提交时间窗、远端任务号是否存在、额度流水状态、脱敏账单线索，以及操作人/复核人。不要把云密钥、录音、原文、对象 key 或密码放入工单或聊天。
2. 若有**真实 TaskId**，由获授权人员在云侧 `GetTaskInfo`、控制台与账单核对该 ID 的受理/计费记录，并确认其归属；返回 FAILED 不等于未受理/未计费。无 TaskId 的超时/5xx 提交**不能**用 TaskKey 调 `GetTaskInfo`，也不能仅凭本地失败状态认定未受理。
3. 若云侧明确证明未受理且无计费，并有第二人复核，才制定原子退预占方案；若确认已受理，先保全经过核验的远端 ID，再制定与任务状态/流水/每日计数一致的恢复方案。现有接口**没有**人工写入 TaskId 或核销流水的授权操作入口，禁止直接用只读队列代替财务审批。
4. 无法唯一匹配云侧受理或计费结果时保留 `RESERVED` 并持续升级，不盲重提、不自动退款。图片 OCR 最终失败与音频远端失败均按实际账单证据分别裁决，不能由 `FAILED` 推断免费。任何账号抹除后的财务核对也不得恢复已删除的个人业务数据。
5. 经批准的更正须在隔离库验证事务、CAS 幂等、并发与回滚，正式执行前核对可验证业务库备份；记录更正前后任务/流水/每日计数及审计轨迹。若票据证据不足、实例不符、数据不一致或备份失败，立即停在待核销态。

当前仅实现候选**只读**发现与限定单测；尚无真实云账单/回调、MySQL 财务验收或获批的写入处置流程，P1-4/P1-5 不因本手册而关闭。
