# S12 真实统计接入 · 记录

版本：v1.0 · 日期：2026-09-24 · 阶段：S12
规格依据：[开发文档](./开发文档.md) §10 指标口径、§7.3 接口；[开发计划](./开发计划.md) §15 S12。

**结论摘要**：统计改为**可追溯聚合**：每个指标都带来源表/时间字段、分母、样本量与来源状态
（REAL/DEMO/PENDING），零分母返回 `null` 而不是 100%，没有数据源的准确率/收入/渠道一律
标「待采集/演示」。后台总览页顶部接入真实指标面板。验证：**176 项单元/切片测试** +
**27 项端到端断言**（固定数据集 COUNT 核对）全部通过。

## 1. 接口与口径元数据

`GET /api/admin/stats/{section}?period=today|7d|30d|quarter` 或 `?from=&to=`

返回 `{section, period, from, to, metrics[]}`，每个指标包含：

| 字段 | 含义 |
|---|---|
| `key/label/value/unit` | 指标键、名称、数值、单位 |
| `sourceTable/timeField` | **来源表与时间字段**（每个真实数字都能追到 SQL 与时间口径） |
| `denominator/sampleSize` | 比率的分母；耗时类指标的样本量 |
| `source` | `REAL` 有来源 / `DEMO` 演示 / `PENDING` 待采集 |
| `note` | 口径说明（例如「时点库存，不与期间处理量相加」） |

时间区间一律**左闭右开** `[from, to)`，业务日界按 Asia/Shanghai。

## 2. 已接真的指标（来源与去重口径）

| 指标 | 来源 | 去重与分母 |
|---|---|---|
| 提交任务量 | `recognition_tasks.created_at` | 按 task 去重，重复提交不增加 |
| 有效报告量 | `report_versions.published_at` 按 task 取**首个**发布 | 角色重算不重复计数（STAT-04） |
| 当前队列 | `recognition_tasks.status` 时点统计 | 时点库存，不与期间量相加 |
| 完成 / 失败 / 无有效语音 | `finished_at`，FAILED 与 INVALID 分列 | INVALID 不并入失败率 |
| 失败率 | 同上 | 分母=完成+失败+无有效语音；**为 0 时返回 null** |
| 平均耗时 | `finished_at - created_at` | 只统计时间字段齐全的样本，返回 `sampleSize` |
| 命中句数 | `violations` + 已发布版本 | 按 `(task_id, sentence_id)` 去重 |
| 风险报告量 / 占比 | `report_versions`（`risk_score >= threshold_snapshot`） | 分母=已发布报告量 |
| 规则命中分布 | `violations.rule_version_id` | 说明是「证据条数」，不是「违规通话数」 |
| 清理情况 | `deletion_jobs.status` | 排队/重试 与 失败 分列 |
| 导出作业 | `export_jobs` | 按状态计数 |
| 审计事件 | `audit_log.action` | 明确「不代表实际播放或下载完成」 |

## 3. 明确不接真的指标（§10 要求）

| 指标 | 状态 | 说明 |
|---|---|---|
| 转写准确率 / 误报率 / 漏报率 | `PENDING` | **需要人工标注真值**，当前无数据源；`confidence` 既不等于准确率也不等于完整度 |
| 新增注册 / 留存 | `PENDING` | 注册链路未接统计口径 |
| MRR / ARPU | `PENDING` | 无付费订阅功能，无数据源 |
| 渠道结构 / CAC | `DEMO` | 未接入真实渠道与投放成本，卡片显式标注「演示」 |

## 4. 权限

- `ADMIN/OPERATOR/INVESTOR` 都可读聚合；响应**只含聚合数字与口径元数据**，
  不含任何个体标识（E2E 直接扫响应断言没有 `userId/taskId/sentenceId/reportVersionId`）。
- INVESTOR 仍拿不到 `/api/admin/recordings` 明细（403）——聚合可见、个体不可见的分界线由后端强制。

## 5. 后台页面改造
